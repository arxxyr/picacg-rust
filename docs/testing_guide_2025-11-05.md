## 本次修改内容

### 1. Tab 键焦点切换功能 ✅

**文件修改**:
- `src/ui/message.rs`: 添加 `TabPressed` 消息
- `src/ui/state.rs`: 添加 `LoginFocus` 枚举和焦点状态管理
- `src/ui/app.rs`: 实现 Tab 键处理逻辑和键盘事件监听

**功能说明**:
- 登录界面支持 Tab 键在用户名和密码输入框之间切换
- 使用 iced 的 `keyboard::on_key_press` 监听键盘事件
- 仅在登录界面激活 Tab 键监听（避免不必要的性能开销）

**测试步骤**:
1. 启动应用，焦点应自动在用户名输入框
2. 按 Tab 键，焦点切换到密码输入框
3. 再按 Tab 键，焦点回到用户名输入框（循环切换）
4. Enter 键应触发登录（原功能保持不变）

### 2. 漫画列表图片显示 Bug 修复 ✅

**问题描述**:
- 漫画列表加载后，封面图片无法显示
- 原因：`ImageLoaded` 消息只将图片 handle 存储到 `categories_state.thumbnails`，未存储到 `comics_list_state.thumbnails`

**修复内容**:
- 修改 `src/ui/app.rs` 的 `Message::ImageLoaded` 处理逻辑
- 添加代码将图片 handle 同时存储到 `comics_list_state.thumbnails`

**代码变更**:
```rust
Message::ImageLoaded { url, handle } => {
    // 存储到分类状态中
    self.state.categories_state.thumbnails.insert(url.clone(), handle.clone());

    // 存储到漫画列表状态中（新增）
    self.state.comics_list_state.thumbnails.insert(url.clone(), handle.clone());

    // ...
}
```

**测试步骤**:
1. 登录后点击"分类"导航按钮
2. 点击任意分类卡片
3. 漫画列表加载后，封面图片应正常显示
4. 点击"上一页"/"下一页"按钮，新页面的图片也应正常加载

## 已知问题

### 1. 未使用的导入警告
- **影响**: 无（仅编译时警告）
- **原因**: 部分 API 端点和模型尚未在 UI 中使用
- **计划**: 后续阶段实现相关功能后自动消除

### 2. 图片加载失败无重试
- **影响**: 低（图片加载失败会显示占位符）
- **原因**: 未实现自动重试机制
- **计划**: 下一阶段添加重试逻辑

### 3. 图片缓存未持久化
- **影响**: 中（应用重启后需要重新下载所有图片）
- **原因**: ImageCache 仅使用内存缓存
- **计划**: 集成磁盘缓存（moka 或 cacache）

### 4. 漫画详情页未完全实现
- **影响**: 高（点击漫画卡片后可能显示空白或加载失败）
- **原因**: 详情页的加载逻辑和章节列表尚未实现
- **计划**: 下一阶段优先实现
